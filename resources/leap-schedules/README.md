## How the numbers were derived

- **Demo** — the duration stated in each module's `demos/<module>/demo-guide.md`, rounded to the 5-minute grid. Where none is stated (sprints 5–8), estimated from the walkthrough's content.
- **Lab** — estimated from the actual task sheet in `labs/<module>/README.md`: number of tasks, and whether they are typing-heavy, design/discussion, or infrastructure-dependent.
- **Presentation** — estimated from slide deck length (~1.5–2.5 min per slide) and the topic.
- Each half-day is filled exactly, so lab times are adjusted by a few minutes where needed to land a session on the fixed 10:30 or 15:00 break.
